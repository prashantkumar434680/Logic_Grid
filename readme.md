# LogicGrid

A full-stack coding platform that allows users to write, compile, and execute code in real-time. Built with modern web technologies, this project focuses on scalability, performance, and user experience.

---

## Features

- Real-time code compilation and execution (multi-language support)
- Secure authentication using JWT
- Problem-solving interface with test cases
- Admin panel to manage problems and submissions
- Fast and responsive UI
- Efficient backend handling multiple user requests

---

## Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### APIs & Tools
- Judge0 API (for code execution)
- JWT Authentication
- RESTful APIs

---

## System Design (High Level)

- Client (React UI) communicates with backend via REST APIs  
- Backend handles authentication, problem management, and user data  
- Code execution is offloaded to Judge0 API (external service)  
- Database stores users, problems, and submissions
